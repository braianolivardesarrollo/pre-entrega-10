Este proyecto es un e-commerce realizado para el curso de JavaScript de Coderhouse.

En esta entrega trabajé con fetch, async/await, try-catch-finally y la librería SweetAlert2.

Los productos se encuentran en el archivo data/productos.json y se cargan mediante JavaScript.

También se utiliza localStorage para guardar los productos y el carrito.

Para ejecutar el proyecto se puede abrir el archivo index.html utilizando Live Server desde Visual Studio Code.
